# CK.Ng.Cris.AspNet.Auth

**Deprecated: replaced by `CK.Ng.Cris.AspNet.Authentication`** ([documentation](https://github.com/signature-opensource/CK-Cris-TypeScript/blob/stable/CK.Ng.Cris.AspNet.Authentication/README.md)).

This package is a tombstone: it has no code, and a project that depends on it (directly or through another package)
fails to build with the `CKDEPRECATED` error. The authentication of the CK stack is now made of Cris commands and an
Authentication Center: see the [migration guide](https://github.com/signature-opensource/CK-Stack/blob/main/Docs/Migrations/v2026.282-to-explo-cris-auth.md).
